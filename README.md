# Phone-Stand-Model
The content of this repository is a CAD model of a adjustable phone stand designed and modeled in Fusion 360. It contains the motion study of the moving parts, detailed dimensions and the design description of the model.
The phone stand model is a generic phone stand with a total of 5 degrees of freedom. 
Any other dimensions that aren't specified and are needed by the viewer can be requested through this email below.

It contains two CAD files, one in the .step format and one in the .fed format. The .f3d format is the native Fusion 360 format and can be opened straight to Fusion 360, but Fusion can also open the .step file while the .step opens directly to SOLIDWORKS but SOLIDWORKS can also open .f3d. This is for user convenience.
